Text Case Converter

Convert text between different cases (uppercase, lowercase, title case, camelCase, snake_case, and more)

Free • No signup required

What This Tool Does

UPPERCASE

Converts all letters to uppercase

Example: HELLO WORLD

lowercase

Converts all letters to lowercase

Example: hello world

Title Case

Capitalizes the first letter of each word

Example: Hello World

Sentence case

Capitalizes only the first letter

Example: Hello world

camelCase

Removes spaces, capitalizes each word except first

Example: helloWorld

snake_case

Replaces spaces with underscores, all lowercase

Example: hello_world
