# CodeSommet — Changements de métadonnées (avant / après)

> Comparaison générée par rendu réel des 120 URL publiques avant et après optimisation.
> **30 titres modifiés, 45 meta descriptions modifiées, 12 H1 corrigés.**
> Résultat final vérifié : **0 titre dupliqué, 0 description dupliquée** sur les 118 pages en 200.

## 1. Logique de fallback du layout (`frontoffice/layouts/app.blade.php`)

| Élément | Avant | Après |
|---|---|---|
| `<title>` | `@yield` + défaut global | inchangé (défaut global conservé, plus aucune page ne l'utilise par accident) |
| Canonical | `url()->current()` (dépend de l'hôte de la requête) | construite sur `config('app.url')` + chemin (stable www/https/proxy) |
| `og:url` | `config('app.url')` (**toujours l'accueil !**) | = canonical de la page |
| `og:type` | codé en dur `website` | `@yield('og_type', 'website')` — les articles émettent `article` |
| Données structurées | 1 bloc Organization concaténé à la main | partiel `structured-data.blade.php`, tableaux PHP + `json_encode` |

La page autonome `/get-quote` (hors layout) : canonical corrigée de `url()->current()` vers APP_URL.

## 2. Raisons des changements par groupe

| Groupe | Pages | Raison |
|---|---|---|
| Hubs (`/tools`, `/locations`, `/industries`) | 3 | Utilisaient le titre/description génériques du site → titres alignés sur le contenu réel (outils gratuits, villes desservies, secteurs) |
| Légal | 5 | Les 5 partageaient le même titre générique → titres « {Politique} \| CodeSommet » + descriptions spécifiques |
| Villes | 24 fichiers lang + 17 blades | 7 titres dupliqués (« Développement Web au Maroc ») → uniques par ville ; 21 descriptions recyclées → uniques et alignées sur les secteurs mis en avant par chaque page ; toponymes francisés (Tanger, Londres, Bruxelles, Copenhague, Le Caire, Barcelone, Lisbonne, Riyad) ; H1 « DUBAI » corrigés sur Casablanca/Marrakech/Rabat/Madrid/Barcelone |
| Services | 4 | Cannibalisation EdTech/E-learning et Télémédecine plateforme/site → intentions différenciées (voir SEO_CANNIBALIZATION_REPORT.md) |
| Outils | 14 fichiers | Artefacts `\'\'` (« l'''IA ») supprimés dans 11 fichiers ; descriptions anglaises traduites (nofollow-link-checker, utm-builder) ; titre franglais corrigé (heading-analyzer) |
| Blog (article) | template | Ajout twitter:title/description/image, og:image:alt ; `og:type=article` désormais effectif |
